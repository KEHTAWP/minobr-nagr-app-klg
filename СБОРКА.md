# Сборка приложения в исполняемый файл Windows

Приложение написано на Python и собирается в один файл, который можно просто
скопировать пользователю — устанавливать Python на его компьютер не нужно.

## Две сборки: какая для чего

Собирается из **одних и тех же исходных файлов**, различаются только
настройки сборки. Править код нужно в одном месте — правки попадут в обе
версии автоматически.

| Что запустить | Что получится | Для кого |
|---|---|---|
| `Собрать exe.bat` | `dist\ПорталНаград.exe` — один файл | Windows 10 и 11 |
| `Собрать exe для Windows 7.bat` | `dist\Портал наград для Windows 7\` — папка | Windows 7 |

Для Windows 10 и 11 пользователю отдают один файл. Для Windows 7 —
**папку целиком**: кроме программы в ней лежит файл запуска и системное
обновление, без которого на «голой» семёрке ничего не стартует. Почему так —
[ниже](#почему-для-windows-7-отдают-папку-а-не-файл).

Обычная версия открывается в своём окне, а если компонента WebView2 нет —
предложит его установить либо откроется в браузере. Версия для Windows 7
всегда открывается в браузере: WebView2 на этой системе не существует.

Проверить обе сборки разом можно файлом `Проверить сборку.bat` — он
пройдётся по всему, что найдёт в папке `dist`.

## Что понадобится один раз

1. **Python 3.10 или новее** — <https://www.python.org/downloads/windows/>
   При установке обязательно отметьте галочку **«Add python.exe to PATH»**.

2. **Microsoft Edge WebView2 Runtime** — движок, который рисует интерфейс.
   На Windows 10 и 11 он, как правило, уже установлен вместе с системой.
   Если приложение при запуске покажет пустое окно, поставьте его отсюда:
   <https://developer.microsoft.com/microsoft-edge/webview2/>

## Порядок сборки

Откройте «Командную строку», перейдите в папку проекта и выполните три команды:

```bat
cd C:\Minobr\MinobrApp

python -m pip install -r requirements.txt
python -m pip install pyinstaller

pyinstaller minobr.spec --noconfirm
```

Готовый файл появится здесь:

```
C:\Minobr\MinobrApp\dist\ПорталНаград.exe
```

Сборка занимает 1–3 минуты. Первый запуск .exe может быть чуть медленнее —
файлы распаковываются во временную папку.

## Это не установщик

`ПорталНаград.exe` — самодостаточная программа, а не установочный файл.
Её ничего не «устанавливает»: файл просто копируют на нужный компьютер
(в любую папку, хоть на рабочий стол или флешку) и запускают двойным щелчком.
Python и библиотеки уже внутри — на компьютере пользователя они не нужны.

## Проверка сборки на чужом компьютере

Перед тем как отдавать файл в работу, стоит убедиться, что внутрь попало
всё необходимое. Для этого в программе есть встроенная самопроверка:

```bat
ПорталНаград.exe --selftest
```

Она откроет окно с отчётом — шрифты, шаблоны бланков, справочник наград и
пробное формирование PDF. Если все четыре строки «в порядке», сборка
исправна. Если нет — в отчёте будет написано, чего именно не хватает.

## Что нужно на компьютере пользователя

Ничего обязательного. Программа умеет работать в двух режимах и сама
выбирает подходящий:

1. **Обычное окно.** Используется, если в системе есть компонент
   Microsoft Edge WebView2 — на Windows 11 и большинстве Windows 10 он уже
   стоит вместе с браузером Edge.
2. **Вкладка браузера.** Если WebView2 нет, программа поднимает локальный
   сервер и открывает интерфейс в браузере по умолчанию. Выглядит и
   работает точно так же; готовый документ попадает в папку «Загрузки».

Интернет не нужен ни в одном из режимов, права администратора не нужны,
в реестр ничего не пишется. Данные никуда не передаются: локальный сервер
слушает только этот компьютер и защищён одноразовым ключом доступа.

### Почему интерфейс всегда идёт через локальный сервер

Оба режима показывают одну и ту же страницу, и оба берут её у локального
сервера. Раньше собственное окно общалось с Python напрямую — через мост
`js_api` библиотеки pywebview, — и это приводило к зависаниям: мост
обслуживает вызовы тем же потоком, который рисует окно, а страница при
запуске могла обратиться к нему дважды подряд. Второй вызов вставал в
очередь за первым и блокировал поток; окно замирало с пустым списком
наград и заголовком «Не отвечает», иногда на минуты.

Сервер этим не страдает: каждый запрос обрабатывается отдельным потоком.
Мост больше не подключается вовсе, а страница обращается к программе
одним и тем же способом в любом режиме — кода стало меньше, а поведение
предсказуемее.

### Журнал запуска

Рядом с программой появляется файл `ПорталНаград-запуск.log` — короткая
запись о том, что происходило при запуске: какой выбран режим, по какому
адресу поднялся сервер, какие были ошибки. Он перезаписывается при каждом
запуске и нужен ровно для одного: если программа опять поведёт себя
странно, этот файл ответит, на чём именно она споткнулась.

Персональных данных в нём нет: всё, что вводится в анкету, туда не
попадает. Если папка защищена от записи, журнал уходит во временную папку
Windows, а точный путь программа показывает в сообщении об ошибке.

Ещё одна защита: программа замечает, что уже запущена, и предупреждает об
этом. Две копии сразу мешают друг другу — движок окна хранит служебные
файлы в общей папке, и второй копии приходится ждать, пока первая их
отпустит.

Принудительно открыть в браузере можно так:

```bat
ПорталНаград.exe --browser
```

## Установщик WebView2 в комплекте (необязательно)

Чтобы на Windows 10/11 без WebView2 программа могла сразу предложить
установку компонента, положите его установщик в папку:

```
assets\webview2\MicrosoftEdgeWebView2Setup.exe
```

Скачать: <https://developer.microsoft.com/microsoft-edge/webview2/> —
раздел **Evergreen Bootstrapper**, файл около 2 МБ. Сборка подхватит его
автоматически, ничего настраивать не нужно.

Без этого файла всё тоже работает — просто вместо предложения установки
программа сразу откроется в браузере.

## Сборка для Windows 7

Для неё нужен **Python 3.8** — последняя версия, работающая на этой системе.
Более новые там просто не запускаются, поэтому обойтись основной сборкой
нельзя. Ставится он отдельно и обычной версии не мешает: они уживаются
на одном компьютере.

Скачать: <https://www.python.org/downloads/release/python-3810/> — внизу
страницы «Windows installer (64-bit)». При установке отметьте
**«Add Python 3.8 to PATH»**.

Дальше — двойной щелчок по `Собрать exe для Windows 7.bat`. Он сам найдёт
нужный интерпретатор (`py -3.8`), поставит библиотеки, соберёт
`ПорталНаград-Win7.exe` и сложит готовый комплект в папку
`dist\Портал наград для Windows 7`.

### Почему для Windows 7 отдают папку, а не файл

На «чистой» Windows 7 нет системного компонента **Universal C Runtime**, и
программа не просто не работает — она даже не запускается: Windows сразу
сообщает, что не хватает файла `api-ms-win-crt-runtime-l1-1-0.dll`.
Проверить это изнутри программа не может, потому что до её собственного
кода дело не доходит.

Поэтому рядом с ней кладётся файл запуска. Он проверяет компонент и, если
его нет, ставит вложенное обновление Microsoft — **KB2999226**. Интернет
не нужен: обновление лежит в той же папке. Делается это один раз, дальше
можно запускать хоть файл запуска, хоть саму программу.

Что оказывается в готовой папке:

```
Портал наград для Windows 7\
    Запустить программу.bat        <- с этого начинает пользователь
    ПорталНаград-Win7.exe          <- сама программа
    Windows6.1-KB2999226-x64.msu   <- обновление Windows
    ПРОЧТИ МЕНЯ.txt                <- памятка для пользователя
```

### Обновление KB2999226: положить один раз

Само обновление в репозитории не хранится — его нужно скачать и положить
сюда:

```
assets\ucrt\Windows6.1-KB2999226-x64.msu
```

Найти в Центре загрузки Microsoft по номеру **KB2999226**, вариант
«для Windows 7 для систем на базе процессоров x64», около 10 МБ. Сборка
подхватит файл сама и положит в комплект.

Без него всё тоже соберётся, но сборка честно предупредит: на «чистой»
Windows 7 пользователю придётся искать обновление самостоятельно.

### Почему эта сборка устроена иначе

* WebView2 на Windows 7 не существует: Microsoft прекратила его поддержку,
  версия 109 была последней. Поэтому окно не создаётся вовсе — интерфейс
  сразу открывается в браузере.
* Из-за этого не нужен и pywebview: в списке зависимостей остаются только
  reportlab и Pillow. Сборка получается меньше и надёжнее.
* Версии библиотек в `requirements-win7.txt` намеренно не закреплены — pip
  сам подберёт последние выпуски, совместимые с Python 3.8.
* В Python 3.9 у функций `hashlib` появился параметр `usedforsecurity`,
  которым пользуется reportlab. На Python 3.8 его нет, и формирование PDF
  падало с ошибкой. Модуль `app/compat.py` убирает этот параметр на старом
  Python — документ получается точно такой же, проверено сравнением
  страниц. На Python 3.9 и новее модуль ничего не делает.
* Локальный сервер не спрашивает у системы сетевое имя компьютера.
  Штатный `http.server` вызывает для этого `socket.getfqdn()`, а на русской
  Windows имя нередко записано кириллицей в кодировке CP1251 — Python ждёт
  UTF-8 и запуск обрывался ошибкой «'utf-8' codec can't decode byte 0xe1».
  Имя и не нужно: сервер слушает только адрес 127.0.0.1, он и подставляется
  напрямую (`AppServer.server_bind`).

### Что должно быть на компьютере с Windows 7

1. **Windows 7 SP1.** Обновление Universal C Runtime (KB2999226) отдельно
   искать не нужно — файл запуска из комплекта поставит его сам, если в
   системе его нет.
2. **Любой современный браузер** — Google Chrome, Яндекс.Браузер, Firefox
   или Opera. Программа найдёт установленный сама, даже если браузером по
   умолчанию остался Internet Explorer.

Internet Explorer не подойдёт: он слишком старый для интерфейса. Если
подходящего браузера на компьютере не окажется, программа честно об этом
скажет и подскажет, что делать, — но работать не сможет, пока браузер не
установят. Поэтому имеет смысл носить установщик браузера на той же
флешке, что и саму программу.

## Проверка перед сборкой

Приложение можно запустить прямо из исходников, не собирая .exe:

```bat
python main.py
```

Так удобнее проверять правки: изменили файл — перезапустили.

## Что входит в сборку

| Папка | Назначение |
|---|---|
| `web/` | интерфейс: главный экран, страницы наград, анкета |
| `app/templates/` | шаблоны официальных бланков, снятые с исходных документов |
| `assets/fonts/` | шрифты для формирования PDF |

Все три папки перечислены в `minobr.spec` — если добавите новые файлы,
проверьте, что они попадают внутрь одной из них.

Ещё две папки внутрь .exe не попадают, а идут рядом с ним в комплекте для
Windows 7: `assets/win7/` (файл запуска и памятка пользователю) и
`assets/ucrt/` (обновление KB2999226). Складывает комплект скрипт
`tools/pack_win7.py`, который вызывается сборкой автоматически.

## Значок приложения

Чтобы у .exe был свой значок, положите файл `assets/icon.ico` — сборка
подхватит его автоматически. Без него будет стандартный значок Windows.

## Поля страницы и печать

Готовые документы идут на принтер, поэтому содержимое обязано укладываться
в зону печати. Границы сняты с самих официальных бланков — их содержимое
лежит в пределах `x 55.3…568.3` и `top 30.1…773.0`, — и закреплены в
`app/pdfkit.py`:

```
MARGIN_LEFT = 55.0     MARGIN_RIGHT  = 570.0
MARGIN_TOP  = 28.0     MARGIN_BOTTOM = 790.0
```

На листе A4 (595×842 pt) это оставляет 55 pt слева, 25 справа, 28 сверху и
52 снизу. Непечатаемая кромка бытового принтера — обычно 4–6 мм (11–17 pt),
так что запас есть со всех сторон.

Правило одно: **что не помещается — переносится, а не сжимается.** Кегль не
уменьшается ни при каких условиях. Не влезла строка — переносится по словам
(а совсем длинное слово — со знаком переноса); не влезла таблица —
продолжается на следующей странице с рамкой; не влез блок подписи или
очередная полоса бланка — открывается новая страница, и бланк продолжается
на ней.

Проверяется это не на глаз: тестовый скрипт формирует все 26 наград на трёх
наборах данных (обычном, длинном и заведомо чрезмерном), разбирает готовые
PDF и убеждается, что ни один символ, линия или рамка не вышли за границы.

## Шрифты

PDF формируется шрифтом Times New Roman, если он есть в системе (на Windows
он есть всегда) — это даёт точное совпадение с исходными бланками. Если
шрифт не найден, используется метрически совместимый Liberation Serif из
папки `assets/fonts`, поэтому вёрстка документа не «поедет» ни при каких
условиях.

## Обновление приложения у пользователей

Приложение не требует установки и не хранит настроек: чтобы обновить
версию, достаточно заменить файл `ПорталНаград.exe`. В комплекте для
Windows 7 меняют только `ПорталНаград-Win7.exe` — файл запуска и
обновление Windows остаются прежними.

Персональные данные, введённые в анкету, нигде не сохраняются — они живут
только в памяти во время заполнения и стираются после того, как PDF записан
на диск.
