# Портал для подачи документов на награды в Калужской области

Настольная программа для Windows, которая готовит комплект наградных
документов: сотрудник выбирает награду, заполняет анкету и получает один
PDF-файл со всеми нужными бланками — остаётся распечатать и подписать.

Разбирается 26 наград четырёх уровней: министерства образования и науки
Калужской области, Калужской области, Министерства просвещения Российской
Федерации и государственные награды Российской Федерации.

## Что программа делает

* **Сама собирает комплект.** Для каждой награды известно, какие бланки в
  него входят: кадровая справка, наградной лист, представление,
  характеристика, согласие на обработку персональных данных.
* **Данные вводятся один раз** и расходятся по всем документам пакета —
  расхождений между бланками не возникает.
* **Следит за сроками подачи.** Награда, приём по которой ещё не открыт,
  недоступна для заполнения; за две недели до конца приёма показывается
  предупреждение.
* **Проверяет требования к награде.** Минимальный стаж, соотношение видов
  стажа между собой, обязательные поля.
* **Воспроизводит бланки один в один.** Каждый глиф и линия ставятся в те
  же координаты, что и в официальном документе.
* **Ничего не сохраняет.** Введённые сведения живут только в памяти и
  стираются сразу после того, как PDF создан.

Интернет для работы не нужен, устанавливать ничего не требуется, права
администратора не нужны.

## Как устроен проект

| Что | Где |
|---|---|
| Запуск программы, выбор режима окна | `main.py` |
| Интерфейс: экраны, анкета, проверки | `web/` |
| Логика: справочник наград, анкета, сроки | `app/` |
| Формирование PDF | `app/pdfkit.py`, `app/forms.py` |
| Шаблоны официальных бланков | `app/templates/*.json` |
| Шрифты и вложенные установщики | `assets/` |
| Сборка комплекта для Windows 7 | `tools/pack_win7.py` |

Шаблоны бланков — это не картинки, а разобранные документы: координаты
каждого символа, линии и рамки. Благодаря этому готовый PDF совпадает с
официальной формой, а вписанные значения встают ровно на её строки.

## Сборка

Подробно — в [СБОРКА.md](СБОРКА.md). Коротко:

* `Собрать exe.bat` — версия для Windows 10 и 11, один файл;
* `Собрать exe для Windows 7.bat` — версия для Windows 7, папка целиком
  (нужен отдельно установленный Python 3.8);
* `Проверить сборку.bat` — самопроверка готовых сборок;
* `Запуск из исходников.bat` — запуск без сборки, для проверки правок.

## Две сборки

Версия для Windows 10 и 11 открывается в собственном окне. Версия для
Windows 7 всегда открывается во вкладке браузера: компонента Microsoft Edge
WebView2 для этой системы не существует. Обе собираются из одних и тех же
исходников — правки достаточно внести один раз.

## Правила, которые нельзя нарушать

Они закреплены в коде и проверяются автоматически:

* содержимое не выходит за поля печати (`x 55…570`, `top 28…790`);
* что не помещается — переносится на новую строку или страницу; кегль не
  уменьшается никогда;
* титульный лист бланка не разрывается между страницами;
* поля для подписей, инициалов и печатей остаются пустыми — их заполняют
  от руки после печати;
* персональные данные нигде не сохраняются.
