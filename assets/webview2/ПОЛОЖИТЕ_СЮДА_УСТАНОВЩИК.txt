Сюда кладётся установщик Microsoft Edge WebView2.

Скачать (раздел "Evergreen Bootstrapper", кнопка Download):
https://developer.microsoft.com/microsoft-edge/webview2/

Скачается файл MicrosoftEdgeWebView2Setup.exe размером около 2 МБ.
Положите его в эту папку и пересоберите приложение.

Если файла здесь нет, приложение всё равно работает: при отсутствии
WebView2 оно откроется в браузере по умолчанию.

Важно: этот компонент существует только для Windows 10 и 11.
На Windows 7 он не устанавливается — там программа всегда будет
открываться в браузере.
