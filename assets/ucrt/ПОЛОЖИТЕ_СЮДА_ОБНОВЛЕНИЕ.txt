Сюда кладут обновление Universal C Runtime для Windows 7.

Зачем: на «чистой» Windows 7 этого системного компонента нет, и
программа не запускается — Windows сообщает, что не хватает файла
api-ms-win-crt-runtime-l1-1-0.dll. Обновление ставится один раз.

Что скачать: KB2999226 для Windows 7 x64, файл называется

    Windows6.1-KB2999226-x64.msu

Найти его можно в Центре загрузки Microsoft по номеру KB2999226
(раздел «Обновление для Windows 7 для систем на базе процессоров x64»).
Размер — около 10 МБ.

Положите файл в эту папку. Сборка «Собрать exe для Windows 7.bat»
подхватит его сама и положит в готовый комплект рядом с программой,
а файл запуска установит его на компьютере пользователя, если там
этого компонента ещё нет.

Без этого файла всё тоже соберётся — просто на «чистой» Windows 7
пользователю придётся ставить обновление самому.
