ПОРТАЛ ДЛЯ ПОДАЧИ ДОКУМЕНТОВ НА НАГРАДЫ В КАЛУЖСКОЙ ОБЛАСТИ
Версия для Windows 7

КАК ЗАПУСТИТЬ

    Двойной щелчок по файлу «Запустить программу.bat».

    Программа откроется во вкладке браузера. Так и задумано:
    всё считается на этом компьютере, интернет не нужен,
    ничего никуда не отправляется.

    Окно, которое появится вместе с браузером, закрывать
    не нужно — пока оно открыто, программа работает.


ПОЧЕМУ НЕ ПРОСТО .EXE

    На «чистой» Windows 7 нередко отсутствует системный
    компонент Universal C Runtime, и тогда запуск обрывается
    сообщением о нехватке файла api-ms-win-crt-runtime-l1-1-0.dll.

    Файл запуска проверяет это сам и, если нужно, ставит
    вложенное обновление Microsoft (KB2999226) — оно лежит
    в этой же папке, скачивать ничего не надо. Делается это
    один раз: дальше можно запускать хоть .bat, хоть .exe.


ЧТО ДОЛЖНО ЛЕЖАТЬ В ЭТОЙ ПАПКЕ

    Запустить программу.bat        — с этого начинается работа
    ПорталНаград-Win7.exe          — сама программа
    Windows6.1-KB2999226-x64.msu   — обновление Windows (на случай,
                                     если его ещё нет в системе)
    ПРОЧТИ МЕНЯ.txt                — этот файл

    Копировать нужно всю папку целиком. Программу можно
    держать где угодно — на диске, на рабочем столе, на флешке.


ЕЩЁ ПОНАДОБИТСЯ БРАУЗЕР

    Google Chrome, Яндекс.Браузер, Mozilla Firefox или Opera —
    любой из них. Internet Explorer не подойдёт: он слишком
    старый для интерфейса программы.

    Если ни одного современного браузера нет, программа честно
    об этом скажет. Его нужно установить один раз.


О ПЕРСОНАЛЬНЫХ ДАННЫХ

    Всё, что вводится в анкету, живёт только в памяти во время
    заполнения. После того как PDF-файл сформирован, эти данные
    стираются: они нигде не сохраняются и никуда не передаются.
